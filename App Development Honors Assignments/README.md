## README
At Randolph High School in New Jersey I took App Development Honors my senior year (2025-2026). It was a class that strictly used JavaScript in a personal growth class that encouraged AI and outside resources to learn JavaScript and coding techniques to create apps. We used Expo Go to code and run our apps. It was taught by Mr. Mathew Horner (The College of New Jersey and Princeton University alum) and I ended with a an A in the course. No AI was used to write code directly. 

Projects (listed in order created which corresponds with difficulty level)
- Forecast App (enter longitude and latitude and uses API to get weather information)
- Memory App (memory game app, try to find matches in least amount of guesses)
- Global Guesser App (similar to geoguessr, given image and pick place on map where you think the image is located)
- Light Saber App (uses gyrsocope in devices to simulate light saber noises based on motion like on/off and slash/crash)
- Painter App (had base drawing code but had to add on to make usable drawing app)
- Tilt Game App (use sensors available in devices to track tilt and motion and make a game using those)

note: in each folder for each project the App.js file has main code used and each has a readme file explaining in detail what the code does
