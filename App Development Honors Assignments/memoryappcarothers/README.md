I have created a Broadway playbill themes match memory game that has 2 different sets of 16 cards, Classic which are all classic musicals and New Gen which are all new Broadway productions. 

For the welcome screen I used ImageBackground to set the background to curtains and the user can press either Classic and New Gen, both will go to the same match screen but dictates the cards using route to carry the choice over to be used to decide the set. I have used flatlist to create the set of buttons or "cards" that are pressed to be turned over/ change the background to match. You are only allowed to flip 2 cards over at once and pressing any other card or the same card does nothing. To flip the cards back over if they are not a match you press the flip button which will update the list that dictates which cards are flipped over and which are not and the amount of turns. If a match is made there is no need to press the flip button the user can keep choosing 2 more cards and the turn counter will increase and the flip button will do nothing if pressed on a match. When all matches are found the finished button will make all cards unclickable, flip all cards over, and set the current turn counter to 0 forcing the user to go back to the welcome screen to play again.

Each time the match screen is loaded the order the cards are in is randomized each time, using a function that assigns each card(item) a number on a list that corresponds to a specific image/card for the correct deck. 

For the high score aspect I used async storage to save the highscore in the async storage, at the start 0 will be displayed if null. When the finished button is pressed a funciton is called to save score which will update the high score, it will check if it is null and if it is or the old high score is less than the amount of turns that round it will update to be saved as the turns it took that round in the storage and displayed.
