# Save the Dolphin Tilt Game

In this tilt game I decided to use the accelerometer over the gyroscope because for my game it is based only on right and left tilt to move the dolphin back and forth, the gyroscpoe was not moving it as easily and was harder to work with the values than the accelermeter so that is why I went with the accelerometer after trying them.

I used GameEngine, physics, and Matter to be able to make this game, using game and engine and physics  made a system that had a ball with the image of a dolphin so it would start at the top and go down according to gravtity and the x value change based on the accelerometer input, the physics and matter make it so the dolphin bounces off of and moves after hitting the different ledges/obstacles and react like real life. The ledges I made so their position and size and random each time by using math.random to make it more intersting and difficult to beat a highscore. The highscore is the lowest time in seconds and is stored using async storage which is displayed on the home screen, when the dolphin hits the bottom it takes a really short amount of time to go back to the home screen but the time recorded is the exact time it hit it not when the scree changes so it is accurate. Also if a new high score is reached it will appear at the top of the game screen before it goes back to the home screen it says "NEW HIGH SCORE" this score will then be displayed under best time on the home screen. I also used matter bodies to add the walls of the screen so the dolphin would bounce off of it and now go beyond by adding that physics. Also there is no way for the user to cheat or break this game, the lack of user input besides tilt helps with this by making it less suscepitble.
